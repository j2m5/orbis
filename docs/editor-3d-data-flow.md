# Поток данных редактора

Все изменения 3D-сцены идут в одном направлении:

`React → EditorStore → OrbisEditorBridge → Orbis / AstroControls / Planet → Three.js`

- React-панели отображают состояние и вызывают только actions соответствующей части `EditorStore`.
- `EditorStore` — единственный источник редактируемых значений для UI, сохранения проекта и будущих undo/redo.
- `OrbisEditorBridge` наблюдает за снимками `orbis`, `controls` и `planet` и передаёт их в 3D-ядро. MobX не участвует в рендер-цикле.
- `Orbis` владеет глобальными настройками сцены, `AstroControls` и главным редактируемым экземпляром `Planet`.
- `AstroControls` применяет настройки камеры и самостоятельно поддерживает состояние пользовательского ввода.
- `Planet` сам владеет своим `object3D` и применяет параметры к нему.

## Как добавить параметр

1. Добавить поле и значение по умолчанию в `src/core/contracts.ts`.
2. Добавить observable-поле, action и поле в `snapshot` нужной секции `EditorStore`.
3. Применить новое поле в `Orbis.applySettings`, `AstroControls.applySettings` или `Planet.applyParameters`. Для дорогих операций сначала сравнить новое значение с текущим.
4. Добавить React-контрол в соответствующую панель.

Сам `OrbisEditorBridge` при этом менять не нужно: он уже передаёт полные типизированные снимки трёх секций.
